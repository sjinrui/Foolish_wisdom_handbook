# Foolish Wisdom Handbook

Foolish Wisdom Handbook 是一个用于 The Fool 整合包的 Minecraft Forge 1.20.1 模组。它提供一本游戏内收集手册，用于查看食物、收藏、进度与相关条目的收集信息。

## 环境

- Minecraft：1.20.1
- Forge：47.4.0
- Java 工具链：17
- 模组 ID：`foolish_wisdom_handbook`
- 当前版本：`1.0`

## 构建

请在项目根目录使用 Gradle Wrapper：

```powershell
.\gradlew.bat check
.\gradlew.bat build
```

在 Linux 或 macOS 上：

```sh
./gradlew check
./gradlew build
```

## 构建产物

构建完成后，模组 jar 会生成在：

```text
build/libs/foolish_wisdom_handbook-<version>.jar
```

对于版本 `1.0`，预期产物名称为：

```text
build/libs/foolish_wisdom_handbook-1.0.jar
```

Git 会忽略构建输出、Gradle 缓存、运行目录、日志和本地 IDE 文件。
